Motor Ampere Protection

Set separate current limits for each motor. Low current can indicate dry running / no water; high current can indicate overload or a mechanical fault.

Minimum current (A)Dry-run limit
Maximum current (A)Overload limit
Trip delayTime filter

Important: thresholds must be set from the motor nameplate and measured normal running current by a qualified electrician. The controller must detect current with a suitable sensor and operate a correctly rated contactor/overload circuit. This app preview only stores the settings locally; it cannot itself stop a real motor. Keep independent hardware overload, short-circuit, phase-failure and emergency protection.

🔒 Firebase Setup

Password protected · Setup only

1. Firebase Connection & google-services.json

ਹਾਲੇ ਕੋਈ google-services.json ਫਾਈਲ ਨਹੀਂ ਚੁਣੀ। ਇਹ preview ਵਿੱਚ ਸਿਰਫ਼ ਪੜ੍ਹੀ ਜਾਵੇਗੀ; Firebase ਨਾਲ ਹੁਣੇ ਕਨੈਕਟ ਨਹੀਂ ਹੋਵੇਗੀ।

Client Web API key / Project ID / App ID are normal Firebase client configuration values. Settings are saved in this browser on this device. Do not put service-account JSON, private keys or Admin SDK credentials here.

2. Firebase Authentication & Google Sign-In

Google provider must also be enabled in Firebase Console → Authentication → Sign-in method, and its authorized domain / OAuth consent details must be configured there. These controls save your chosen settings in this preview; they do not switch Firebase providers live until the app and backend are connected.

3. FCM Push Notifications

Token ਇਸ browser ਦੇ local storage ਵਿੱਚ save ਹੋਵੇਗਾ। ਅਸਲੀ FCM token Firebase SDK ਐਪ ਰਜਿਸਟਰ ਹੋਣ ਤੋਂ ਬਾਅਦ ਬਣਾਉਂਦਾ ਹੈ; ਇਹ HTML ਆਪਣੇ ਆਪ token generate ਨਹੀਂ ਕਰ ਸਕਦੀ।

FCM server credentials are not entered here. Send notifications through a trusted Cloud Function / server using Firebase Admin SDK. Android notification permission and sound channel must also be configured in the app.

4. Admin Password

This is a local preview lock only. Production admin authorization must be enforced by Firebase Authentication custom claims / server-side roles.
